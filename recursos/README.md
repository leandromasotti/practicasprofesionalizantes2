## Criterio para incorporar recursos

- **Formato abierto cuando sea posible.** Preferir Markdown, SVG o diagramas como código ([Mermaid](https://mermaid.js.org/), [PlantUML](https://plantuml.com/es/)) por sobre binarios: se versionan, se comparan entre versiones y se corrigen sin herramientas propietarias.
- **Un solo formato por documento.** Publicar el PDF y no también el `.docx` de trabajo, para evitar que se desincronicen.
- **Peso.** Evitar archivos grandes: un repositorio de material de estudio debe poder clonarse rápido.
- **Atribución.** Toda imagen o material de terceros debe indicar su fuente.
