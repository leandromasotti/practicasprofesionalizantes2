# Presentación

Bienvenido a **Prácticas Profesionalizantes II**.

Esta asignatura representa uno de los espacios más importantes de la carrera, ya que tiene como objetivo acercar al estudiante al ejercicio profesional del Analista de Sistemas.

Hasta este momento de la carrera probablemente hayas aprendido conceptos relacionados con programación, bases de datos, análisis de sistemas, desarrollo web, sistemas operativos y diversas tecnologías.

Sin embargo, en una empresa el trabajo de un Analista de Sistemas va mucho más allá de escribir código.

Los proyectos de software requieren planificación, organización, comunicación, documentación, trabajo en equipo y capacidad para resolver problemas complejos.

Esta materia busca justamente desarrollar esas competencias.

Durante el cursado trabajarás como si formaras parte de una empresa de desarrollo de software.

Cada actividad intentará simular situaciones reales que ocurren diariamente dentro de una organización.

No solamente aprenderás teoría.

Aprenderás a pensar como un profesional.

---

# ¿Qué son las Prácticas Profesionalizantes?

Las Prácticas Profesionalizantes constituyen un espacio curricular orientado a integrar los conocimientos adquiridos durante la carrera con situaciones propias del ámbito laboral.

Su finalidad no consiste únicamente en desarrollar habilidades técnicas, sino también en formar profesionales capaces de desenvolverse en organizaciones reales.

Durante estas prácticas los estudiantes deberán analizar problemas, trabajar en equipo, elaborar documentación técnica, comunicarse con clientes, planificar proyectos y tomar decisiones fundamentadas.

En otras palabras, las Prácticas Profesionalizantes permiten reducir la distancia entre el aula y el mundo laboral.

---

# ¿Por qué son importantes?

En muchas ocasiones un estudiante posee buenos conocimientos de programación, pero desconoce cómo se desarrolla un proyecto dentro de una empresa.

Por ejemplo:

- ¿Cómo se organiza un equipo de desarrollo?
- ¿Quién conversa con el cliente?
- ¿Cómo se planifica un proyecto?
- ¿Qué documentación debe elaborarse?
- ¿Cómo se controlan los tiempos?
- ¿Cómo se gestionan los cambios?
- ¿Qué sucede cuando aparecen nuevos requerimientos?

Estas son situaciones que rara vez pueden comprenderse únicamente mediante ejercicios de programación.

Las Prácticas Profesionalizantes buscan responder estas preguntas mediante proyectos similares a los que encontrarías en una empresa.

# La diferencia entre aprender y trabajar

Durante gran parte de la carrera los ejercicios suelen ser pequeños.

Por ejemplo:

- desarrollar un algoritmo;
- crear una base de datos;
- construir una página web;
- realizar una consulta SQL.

En cambio, en el ámbito profesional los proyectos poseen características muy diferentes.

Generalmente:

- participan varias personas;
- existen plazos de entrega;
- aparecen cambios constantemente;
- intervienen clientes reales;
- existen restricciones de tiempo y presupuesto;
- es necesario documentar todo el trabajo realizado.

En consecuencia, desarrollar software implica mucho más que programar.

# ¿Qué significa pensar como un Analista?

Un Analista de Sistemas no comienza escribiendo código.

Antes de desarrollar una solución necesita comprender completamente el problema.

Para ello debe responder preguntas como:

- ¿Quién utilizará el sistema?
- ¿Cuál es el problema que intenta resolver?
- ¿Qué información necesita el usuario?
- ¿Qué restricciones existen?
- ¿Qué recursos posee la organización?
- ¿Qué riesgos pueden aparecer?

Solo después de comprender el problema será posible diseñar una solución adecuada.

Esta forma de pensar constituye una de las competencias más importantes que desarrollarás durante la materia.

# Nuestra forma de trabajar

Durante el año trabajaremos mediante proyectos grupales.

Cada grupo actuará como un pequeño equipo de desarrollo.

El docente asumirá distintos roles según la actividad:

- Cliente.
- Líder de proyecto.
- Consultor.
- Director de empresa.
- Revisor técnico.

De esta manera se intentará reproducir situaciones similares a las que ocurren dentro de una organización.

---

# Proyecto Integrador

Gran parte de las actividades estarán relacionadas con un proyecto de software que evolucionará durante toda la cursada.

Sobre dicho proyecto aprenderemos a:

- analizar problemas;
- definir el alcance;
- planificar tareas;
- estimar tiempos;
- elaborar cronogramas;
- identificar riesgos;
- modelar el sistema;
- documentar decisiones;
- presentar soluciones.

El objetivo no consiste únicamente en obtener un producto final, sino en comprender todo el proceso necesario para desarrollarlo.

Para obtener el mayor beneficio de la cursada se recomienda:
